# Locale Review

다국어 번역 PR을 한 화면에서 검토하는 **완전한 정적 웹앱**입니다. 서버, 데이터베이스, 런타임 API가 필요하지 않습니다. 원문, 기존 번역, 제안 번역을 나란히 보고 변경 라인에 인라인 댓글을 남길 수 있습니다.

## 개발 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 정적 페이지 만들기

```bash
npm run build
```

빌드 결과는 `dist/` 폴더에 생성됩니다. 이 폴더만 GitHub Pages, Nginx, S3, Cloudflare Pages 등 원하는 정적 호스팅에 올리면 됩니다. 모든 리소스 경로가 상대 경로라서 하위 경로에서도 동작합니다.

로컬에서 빌드 결과를 확인하려면:

```bash
npm run preview
```

## 포함된 기능

- 원본 / 변경 전 / 변경 후 3열 비교와 열별 표시 토글
- 번역 단위 높이 정렬 및 세로 스크롤 동기화
- 한국어, 중국어, 프랑스어, 일본어, 아랍어 샘플과 RTL 표시
- 줄번호, 추가/삭제 표시, 변경 부분만 보기
- 변경 후 라인에만 인라인 댓글 작성
- 즉시 등록과 Pending review 일괄 제출 데모
- 플레이스홀더 누락 경고
- 프로젝트 설정, 토큰, 댓글 초안의 브라우저 저장
- 작은 화면용 가로 패널 전환 레이아웃

## 데이터 및 GitHub 연동

현재 데이터와 제출 동작은 화면 흐름을 검증하기 위한 샘플입니다. 브라우저에서 GitHub REST API를 직접 호출하도록 확장할 수 있습니다. 설정의 토큰은 데모 요구사항에 따라 `localStorage`에 저장되므로 실제 운영용 토큰을 넣지 마세요.

샘플 locale과 번역 단위는 `src/App.tsx`의 `locales` 객체에서 수정할 수 있습니다.
